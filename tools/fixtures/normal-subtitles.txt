# 用途：证明「长文本跑的那组规则不会把正常字幕当注入」。
# 为什么必须固化：一度打算往长文本池里补三条语义规则（冒充官方 / 威胁施压 / 反向试探），
#   我拿这三条**原样正则**跑这批语料，命中 8/20（40%）——字幕动辄几千字，等于必然报警。
#   这个数字是目前唯一支撑「不加规则」的证据，只写在报告里迟早会被忘掉，所以固化成可重跑的判据。

# 语料里**故意**保留了会踩到别的规则的说法（「我是做客服的」「内部授权」「让我转告你」
#   「快点来不及了」「你证明一下」）：它们在 SUSPECT_ALL（短文本/评论）里会命中，
#   在 SUSPECT_HIGH（长文本/字幕）里不该命中。这两个池子的差异就是本文件要钉住的东西。
